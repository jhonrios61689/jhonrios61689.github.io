Árbol Jerárquico del DOM

Representación estructurada de los nodos HTML5, identificadores (#id), clases CSS (.class), modales nativos (<dialog>) y eventos dinámicos de JavaScript en Dulce Tentación.

<etiqueta> Elemento HTML5 #id Identificador único .clase Selector CSS JS Event Interacción DOM
  • document Raíz del Document Object Model (HTML5)
    • <html lang="es">
      • <head> Metadatos, título, favicon, css/styles.css y js/app.js (defer)
      • <body> Cuerpo principal de la interfaz de clientes
        • <a> .skip-link Accesibilidad: saltar directo a #contenido
        • <header> .header.wrap Barra superior fija con navegación, sesión y carrito
          • <a> .brand Logo assets/img/logo.png + nombre de marca
          • <nav> #menu .nav Enlaces: Inicio, Postres, Cafés, Nosotros
          • <div> .header-actions Acciones de usuario y carrito
            • <button> #open-auth .user-trigger click → openAuthDialog() Contiene #user-label
            • <button> #open-cart .cart-trigger click → showModal() Contiene contador #cart-count
            • <button> #menu-toggle .menu-trigger click → toggle menu
        • <main> #contenido Contenedor principal de las 5 secciones de la tienda
          • <section> #inicio .hero Portada principal, estadísticas y composición visual
          • <section> .categories.wrap Tarjetas de filtro rápido: Postres (14) y Cafés (6)
          • <section> .featured.wrap Selección de la vitrina
            • <div> #featured-products .product-grid.featured-grid Renderizado dinámico JS
          • <section> #catalogo .catalog.wrap Catálogo completo conectado a MySQL sistema_dulcetentacion
            • <div> .catalog-controls
              • <div> .filters click [data-filter] Botones: Todos, Postres, Cafés
              • <label> .search Input buscador #search input → renderCatalog()
            • <div> #products .product-grid 20 tarjetas <article class="product-card">
          • <section> #marca .story.wrap Historia de marca e ilustración de mascota
        • <footer> .footer Pie de página, enlaces legales, redes y dirección Maps
          • <div> .wrap.footer-inner
            • <a> .brand
            • <nav> click [data-info] Botones: Contacto, Condiciones, Privacidad
            • <ul> .footer-social Instagram, Facebook, WhatsApp y Dirección Google Maps (Call 8 #5-20 parque principal)
          • <p> .prototype-note Barra de Copyright (#9ACDB5)
        • <dialog> #product-dialog Modal de detalle de producto y selector de cantidad
        • <dialog> #cart-dialog .cart-dialog Modal lateral del carrito (#cart-items, #cart-total, #checkout-form)
        • <dialog> #info-dialog .info-dialog Modal informativo (Contacto, Condiciones, Privacidad)
        • <dialog> #auth-dialog .auth-dialog Modal de Login / Registro de clientes conectado a tabla clientes
        • <div> #toast .toast Notificación flotante accesible (role="status")
  • document Portal Independiente (administracion/index.php)
    • <body>
      • <main> #access .access Vista de autenticación por rol
        • <section> .access-brand Identidad visual y mascota
        • <section> .access-form
          • <form> #login-form submit → adminApi.login()
            • <input> #login-email Correo institucional (vacío por defecto)
            • <input> #login-password Contraseña (vacío por defecto)
            • <button> #btn-login-admin roleType="administrador" Valida tabla administradores
            • <button> #btn-login-empleado roleType="empleado" Valida tabla empleados
      • <div> #panel .panel Área de trabajo interna (oculta hasta iniciar sesión)
        • <aside> .sidebar Menú lateral: Resumen, Productos (20), Empleados, Clientes, Movimientos y Roles
        • <div> .workspace
          • <header> .topbar Usuario activo (#active-user-name, #active-user-role)
          • <main> .content Contenedor dinámico #view-content con botones Editar, Borrar y columna Empleado en ventas
      • <dialog> #editor Formulario modal para crear/editar registros y ajustar stock
      • <div> #notification Avisos de confirmación de base de datos
